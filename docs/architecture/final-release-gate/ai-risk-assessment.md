# AI risk assessment

Aligned to NIST AI RMF Generative AI Profile and OWASP AI Testing Guide v1.

Mandatory zeros: system prompt disclosure, credential disclosure, cross-tenant retrieval,
unauthorized tool execution, Gateway bypass, unknown approved table/column,
invented financial numeric result, masked value reconstruction.

Model immutability: hash, quantization, context, sampling, prompts, llama.cpp build pinned in RC manifest.
