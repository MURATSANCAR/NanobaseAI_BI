# Customer acceptance

Technical GO is insufficient. Required signers include Product Owner, Security, Platform,
Data Engineering, BA, DB Owner, Customer Tech + Business; + Oracle DBA / SAP Functional+Basis+Security when claimed.

Per pilot tenant: onboarding, schema scan, metrics, 50–100 business questions, unauthorized/ambiguous,
export, feedback, audit, roles, performance, errors.

Approval is metric/datasource/tenant scoped — not transferable across customers.
