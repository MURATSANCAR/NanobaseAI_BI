# Editör arayüzü

Planlanan bağımsız React/TypeScript/PDF.js arayüzünün köküdür. Bu altyapı
teslimatında kullanıcı ekranları henüz uygulanmadı. P1 kaynak paneli ve P5
inceleme akışı burada geliştirilecek; BI iç kodu doğrudan import edilmeyecek.

Tüm ekranlar 320, 390, 768 piksel ve masaüstünde gerçek tarayıcıyla doğrulanır.
Sayfa yatay taşması `overflow:hidden` ile gizlenmez. API'nin altyapı durumu
kitap analizi veya editör onayı gibi gösterilmez.
