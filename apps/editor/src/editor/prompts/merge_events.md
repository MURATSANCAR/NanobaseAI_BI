Yalnız AYNI olayın iki kez yazılmış kayıtlarını grupla (aynı an, aynı eylem, aynı ya da komşu sayfa). Art arda gelen farklı eylemler (teklif etmek ile getirmek, başlamak ile izlemek) ayrı olaylardır, birleştirilmez. Aynı olayı anlatan kayıtları grupla (`groups`: birleşecek id listeleri ve birleşik tek cümlelik özet). Farklı modalitedeki kayıtları (ör. PLAN ile REALIZED) ASLA birleştirme: plan ile gerçekleşmesi iki ayrı olaydır.
Sonra REALIZED ve MEMORY olayları hikâyedeki GERÇEK oluş sırasına göre sırala (`story_order`: id listesi). MEMORY olayları geçmişte olduğu için anlatıldığı sayfadan önce yer alabilir. Türkçe yaz.
